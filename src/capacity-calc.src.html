디코드 스텝 t(B) = 가중치/BWeff + KVseq/BWeff·B + 오버헤드 · 프리필 R = FLOPSeff / (2·활성파라미터) · 정상상태 X = 1 / (O·t(B)/B + P/R) · 동시성은 Little's law N = X·R체류.

KV 공식은 어텐션 구조별로 갈립니다 — GQA 2·L·kv_heads·head_dim·C, MLA L·(lora_rank+rope_dim)·C(압축 잠재 1벌), SWA C→min(C,window), 하이브리드는 글로벌 레이어만 풀 컨텍스트. 구조를 잘못 잡으면 데이터가 최신이어도 답이 틀립니다.

최적화는 두 부류다. 양자화·prefix cache·CUDA graph 처럼 계수를 움직이는 것들은 η 와 스텝 오버헤드가 흡수하므로 캘리브레이션이 자동 반영한다. 반면 식을 바꾸는 추측 디코딩(스텝당 토큰 수)과 PD 분리(프리필이 디코드 시간을 안 훔침)는 위 패널에서 직접 지정한다. 추측 디코딩의 수용 길이는 배치가 커지면 떨어지는데 여기서는 상수로 둔다 — 큰 배치에서는 낙관적이다.

TTFT p95는 M/M/1 근사(평균×3)라 이 모델에서 가장 약한 항이며, 연속 배칭 스케줄러 실측으로 보정해야 합니다. 추정 표시가 붙은 계수는 미검증 세대 기본값입니다.
